# ostis_ps_user_ecosystem

Directory containing the source code (not part of this vault — a regular C++/CMake
folder next to it: `../ostis_ps_user_ecosystem/`). The `TrustModule` module implements
twelve agents from [[Agent Index]]. Build with `CMakeLists.txt` in this
directory; CLI for manual launch — `scripts/update_trust.py`.

Symlinked to `ostis-web-platform/ostis_ps_user_ecosystem` for building as part of the platform.
